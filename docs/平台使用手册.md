# 坝上植物实习小助手使用手册

## 一、平台入口

启动后访问 `http://127.0.0.1:4173/` 或开发地址 `http://127.0.0.1:5173/`。桌面端使用左侧导航，移动端使用底部四栏导航。

## 二、特征图谱

1. 点击照片上的花、叶、茎、果实或整体热点。
2. 右侧查看当前器官的观察项目和特征分类。
3. 点击特征分类可查看对应植物记录。

图谱用于学习形态观察方法，不直接给出物种鉴定结论。

## 三、植物名录

1. 在左侧输入中文名、拉丁名、科属或形态特征。
2. 可按科、生活型、生境、花色和器官特征筛选。
3. 点击植物后，左侧搜索、筛选条件和滚动位置会保留。
4. 图片区可切换实习样本与 iPlant 参考图，点击照片进入放大预览。
5. 使用左右方向键切换上一种或下一种植物；输入框获得焦点时不会触发切换。
6. 无结果时点击“清除搜索与筛选”恢复全部记录。

移动端点击“搜索 290 种植物”打开索引，选择植物、点击关闭按钮或点击遮罩均可关闭。

## 四、语义识别

输入实际观察到的特征，例如：

```text
多年生草本，湿草地，黄色头状花序，有舌状花，叶互生
```

- `Enter`：生成候选；
- `Shift+Enter`：换行；
- 点击输入区右上角的关闭图标可清空本次观察与候选；
- 输入“帮我区分问荆和节节草”可进入双植物对比；
- 返回名录后再回到语义识别，本次会话中的查询与结果仍会保留。

候选中的“支持特征”“冲突特征”和“待确认”用于决定下一步观察。候选顺序不是最终鉴定结果。

## 五、图片识别与样本补录

### 图片检查

1. 选择同一植株的 1 至 8 张图片。
2. 为每张图片标注全株、花、叶、茎、果实或生境。
3. 点击“检查图片与器官覆盖”。
4. 根据提示补拍缺失器官。
5. 点击“保存为待复核”可保存到当前浏览器。

重复图片不会再次加入，超过 8 张会给出提示。再次选择同一个文件也能正常触发。

### 样本补录

切换到“样本补录”，填写暂定名称、正式名录关联、生境、日期和说明。资料保存在浏览器 IndexedDB，状态固定为待复核，不会自动写入正式知识库。

### 模型服务

本机 BioCLIP 服务启动后，页面显示“BioCLIP 已就绪”，按钮名称为“BioCLIP 识别”。候选默认返回 10 条，点击候选可进入植物名录。百分比是 290 条本地记录内的相对得分，不是真实鉴定概率；结果需要结合图片、结构化特征和教师复核使用。

服务尚未启动时按钮保持禁用，不会生成演示候选。具体启动、换机和 GPU 配置见 [BioCLIP 模型使用与配置教学](BioCLIP模型使用与配置教学.md)。

## 六、数据状态

点击右上角 `V2` 可查看：

- 正式与待定种记录数；
- iPlant 参考图和实习样本数；
- 本地覆盖物种数；
- 待复核图片与隐私处理说明。

## 七、拍摄建议

- 全株与生境至少各留一张；
- 花正面和完整花序侧面分开拍摄；
- 叶片需包含正面、背面和连续茎节上的叶序；
- 茎需记录棱、沟、节、毛和刺；
- 果实尽量同时记录未熟和成熟阶段，并放入尺度参照。

## 八、数据与隐私

平台派生的实习图片已剥离 EXIF。公开 JSON 不保存发送者 ID、群消息 ID或精确 GPS。浏览器本地补录不会自动上传到网络，除非部署人员明确配置并调用外部模型服务。
