# 坝上植物实习小助手使用手册

## 一、平台入口

启动后访问命令行中 Vite 显示的地址。常用开发地址为 `http://127.0.0.1:5173/`；若端口已占用，Vite 会显示另一个端口，不能只凭端口是否返回页面判断。桌面端使用左侧导航，移动端使用底部四栏导航。图片检查与识别已合并到“识别”，样本补录从识别页进入。

## 二、特征图谱

1. 点击照片上的花、叶、茎、果实或整体热点。
2. 右侧查看当前器官的观察项目和特征分类。
3. 点击特征分类可查看对应植物记录。

图谱用于学习形态观察方法，不直接给出物种鉴定结论。

## 三、植物名录

1. 在左侧输入中文名、拉丁名、科属或形态特征。
2. 可按科、生活型、生境、花色和器官特征筛选。
3. 点击植物后，左侧搜索、筛选条件和滚动位置会保留。
4. 支持常见别称、旧拉丁名和已校订的历史误写检索；结果会标注“别称”或“原名校订”，说明命中原因。
5. 若从图谱或教学页打开筛选范围外的植物，列表顶部会保留当前条目，并提供“清除筛选并定位”。
4. 图片区可切换实习样本与参考图库，点击照片进入放大预览。
5. 使用左右方向键切换上一种或下一种植物；输入框获得焦点时不会触发切换。
6. 无结果时点击“清除搜索与筛选”恢复全部记录。

移动端点击“搜索 290 种植物”打开索引，选择植物、点击关闭按钮或点击遮罩均可关闭。

图片放大后可点击右上角“关闭”或图片外的深色区域退出；桌面端还可按 `Esc`。关闭后页面会回到刚才点击的缩略图位置。

## 四、联合识别

联合识别支持三种输入方式：只写观察记录、只上传照片、同时提交观察记录与照片。输入实际观察到的特征，例如：

```text
多年生草本，湿草地，黄色头状花序，有舌状花，叶互生
```

- `Enter`：开始识别；
- `Shift+Enter`：换行；
- 点击输入区右上角的关闭图标可清空本次观察与候选；
- 输入“帮我区分问荆和节节草”可进入双植物对比；
- 可一次选择同一植株的 1 至 8 张照片，并为每张标注全株、花、叶、茎、果实、生境或根；
- 返回名录后再回到联合识别，本次会话中的文字查询仍会保留。

只输入文字时，平台使用结构化知识库与反向索引；只上传照片时，平台使用 BioCLIP v1.7；两者同时输入时，文字中的生活型、花色、叶形和生境会进入 v1.7 性状与生态约束。页面分别展示图片候选和结构化特征证据，不把两种证据包装成一个无法解释的总概率。

候选中的“支持特征”“冲突特征”和“待确认”用于决定下一步观察。所有候选均为待复核结果。

## 五、图片检查与样本补录

### 图片检查

识别页会自动对已选照片执行格式、尺寸和器官覆盖检查。需要保存后续实习样本时，点击识别页的“样本补录”进入独立记录页。

1. 选择同一植株的 1 至 8 张图片。
2. 为每张图片标注全株、花、叶、茎、果实或生境。
3. 点击“检查图片与器官覆盖”。
4. 根据提示补拍缺失器官。
5. 点击“保存为待复核”可保存到当前浏览器。

重复图片不会再次加入，超过 8 张会给出提示。再次选择同一个文件也能正常触发。

### 样本补录

切换到“样本补录”，填写暂定名称、正式名录关联、生境、日期和说明。资料保存在浏览器 IndexedDB，状态固定为待复核，不会自动写入正式知识库。

### 模型服务

本机 BioCLIP v1.7 服务启动后，联合识别页显示实际版本与设备。候选默认返回 10 条，点击候选可进入植物名录。百分比是 290 条本地记录内经过提示词集成和可选先验约束后的相对得分，不是真实鉴定概率。

服务尚未启动时按钮保持禁用，不会生成演示候选。具体启动、换机和 GPU 配置见 [BioCLIP 模型使用与配置教学](BioCLIP模型使用与配置教学.md)。

## 六、易混淆物种辨析

底部“辨析”进入实习教学文档，分为两个视图：

- **物种辨析**：8 组课程，包含优先观察部位、常见误判、物种诊断要点、资料页码和证据判断题。点击物种可进入完整档案。
- **实习方法**：4 讲课程，包含种–面积曲线、阴阳坡生态序列、群落描述和放牧干扰比较。

课程依据《植物特征总结》和《B组植物地理实习汇报》整理。汇报中的名录外名称只标记为待核对；教学内容用于组织观察，分类结论仍需植物志检索与教师复核。

## 七、数据状态

点击右上角 `V2` 可查看：

- 正式与待定种记录数；
- 参考图库和实习样本数；
- 本地覆盖物种数；
- 待复核图片与隐私处理说明。

“最近导入”显示最新每日样本包的日期、图片总数、正式挂接数、待复核数和器官待标注数。待复核池优先展示最新提交的名称。

## 八、拍摄建议

- 全株与生境至少各留一张；
- 花正面和完整花序侧面分开拍摄；
- 叶片需包含正面、背面和连续茎节上的叶序；
- 茎需记录棱、沟、节、毛和刺；
- 果实尽量同时记录未熟和成熟阶段，并放入尺度参照。

## 九、数据与隐私

平台派生的实习图片已剥离 EXIF。公开 JSON 不保存发送者 ID、群消息 ID或精确 GPS。浏览器本地补录不会自动上传到网络，除非部署人员明确配置并调用外部模型服务。
